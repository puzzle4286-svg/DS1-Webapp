PurposeCreate + Update of the CRUD roundtrip. (FR-06, FR-08) 1 Type, required. Default replenishment. URL can prefill: ?type=&productId=&quantity=. 2 Product, required. Options from GET /api/products; shows current + recommended stock. 3 Quantity, required, integer 1–100. 4 Reason, required for Return and Usage report. Options depend on type. 5 Notes, max 500 characters, live counter. 6 Save → create: POST /api/requests (201) · edit (?id=12): loads with GET /api/requests/12, saves with PUT /api/requests/12 (200). Then → S5 with success message. Button disabled while saving. ErrorsBrowser checks fields first; the server checks again. 400 → messages shown under the fields. 409 → "This request can no longer be changed." Cancel → back to S5 without saving.
